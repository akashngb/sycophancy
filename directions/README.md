# directions/

Each person or pair takes a research direction after the shared benchmark
is in place. Put your working folder here. Keep it self-contained: notes,
plots, and any scripts specific to your direction live inside the folder.
Code that other people will reuse should go in `src/syco/`, not here.

Suggested layout for your folder:

```
directions/<your-name-or-topic>/
  README.md         # pitch and running notes
  notes/            # literature notes, meeting notes
  plots/            # saved figures you want to reference
  config.yaml       # if you have a direction-wide config
```

Current directions (fill in as people claim them):

- interpretability — probes, activation patching
- interventions — fine-tuning vs activation steering
- multi-turn conversations
- coding agents
- agent-to-agent sycophancy
- vision-language models
- feedback and flattery sycophancy
